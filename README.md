# 🐾 ANIMORA

> **Explore. Discover. Interact.**

ANIMORA is an interactive cartoon-style animal world designed to make exploring animals feel like stepping into an animated movie.

Each animal has its own environment, visual identity, animations, and interactive experience.

## ✨ Features

- 🐾 Interactive animal world
- 🎬 Cinematic cartoon-style environments
- 🐱 Individual pages for different animals
- 🖱️ Custom animal-foot mouse interaction
- 🎨 Playful rounded cartoon typography
- 🌄 Unique backgrounds for different animals
- ✨ Smooth animations and transitions
- 🌙 Immersive visual experience
- ⚡ Lightweight frontend implementation

---

## 🐾 Animal Experience

Each animal page is designed around its own environment and personality.
